# AleksControllerTester is now InputLab

**AleksControllerTester has moved into [InputLab](https://github.com/moneks1106-code/InputLab): one free Windows app for your controllers, your mouse and the PC they run on. This repository is no longer updated.**

### ➡️ [Download InputLab](https://github.com/moneks1106-code/InputLab/releases/latest)

### 💬 [Join the InputLab Discord](https://discord.gg/3kEktvD4zm)

## Everything from AleksControllerTester, in InputLab

- The controller live view and the quick tests: Stick Motion with the delivery score, Idle Drift, Button Burst, Trigger Sweep and Stick Range.
- Advanced / Lab, Timeline, Compare and the Markdown report.
- The same honesty: InputLab timestamps every Raw Input HID report as Windows hands it over (host-delivery timing) and shows latency only as labelled lower bounds.

## New in InputLab

- **Mice** in the same app: everything from AleksMouseTester, with a fairer mouse score.
- **Home:** your PC at a glance, every rating with its source.
- **System:** the USB map, the power settings with Restore, and Interrupts: which CPU core your devices use, with a drag-and-drop layout you can undo.
- A wireless mouse doctor and USB timing for mice.

## Your old runs come with you

In InputLab, **Controller › Compare › Import from AleksControllerTester** copies the runs AleksControllerTester saved. The old files are only read, never changed, and AleksControllerTester can stay installed next to InputLab.

## Old versions

The AleksControllerTester releases stay on this page for reference; v1.0.3 was the last one. They get no more updates. Please report problems and results in [InputLab's issues](https://github.com/moneks1106-code/InputLab/issues).
